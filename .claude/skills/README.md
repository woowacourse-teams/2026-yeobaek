# Project Skills

팀 공용 Claude Code 스킬 디렉터리입니다. 저장소 루트에 있으므로 저장소 안 어느 디렉터리(루트, `backend/` 등)에서 Claude Code를 실행하든 별도 설치 없이 세션 시작 시점부터 바로 사용할 수 있습니다.

## grill-me / grilling

- `/grill-me`: 계획이나 설계를 설명한 뒤 호출하면, 모든 결정 사항이 해소될 때까지 집요하게 질문하는 인터뷰 세션을 시작합니다. 내부적으로 `grilling` 스킬을 호출하는 래퍼입니다.
