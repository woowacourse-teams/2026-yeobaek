# 비공개 static 메서드

운영·테스트 코드의 Java 비공개 메서드를 새로 작성하거나 수정할 때 적용한다.

`private` 메서드는 인스턴스 메서드를 기본으로 한다. 상태를 읽지 않는다는 이유만으로
`static`을 붙이면 별도의 정적 호출 목적이 있는지 해석해야 하므로, 다음 경우에만 사용한다.

- 정적 팩터리에서 직접 호출하는 헬퍼
- JUnit 기본 수명주기에서 필요한 `@MethodSource` 제공자
- 의도적으로 정적 유틸리티로 설계된 클래스의 헬퍼

기존 `private static`을 수정할 때도 호출 문맥을 확인한다. `static` 여부를 맞추기 위해
메서드 본문·호출 의미·클래스 구조를 불필요하게 바꾸지 않는다. 상수·공개 API는 이 지침의 범위 밖이다.
