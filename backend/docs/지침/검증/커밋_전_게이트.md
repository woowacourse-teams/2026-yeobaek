# 커밋 전 게이트

## 검증과 커밋

- 코드 변경을 마친 작업 단위마다 커밋 전에 `backend/`에서 `./gradlew build`를 한 번 수행한다.
  컴파일·전체 테스트·PMD·SpotBugs를 함께 실행한다. 테스트에는 Docker가 필요하다.
- 실패하면 원인을 수정하고 다시 검증한다. 게이트 이후 코드를 바꿨다면 다시 수행한다.
- 변경한 동작에 맞는 테스트를 확인하고, 해당하는 [작업별 지침](../README.md)과 대조한다.
- 커밋은 독립적으로 컴파일 가능한 작업 단위로 나누고 Conventional Commits 형식을 사용한다.
  같은 최종 트리에 대한 전체 게이트를 중간 커밋마다 반복하지 않는다.
- 문서·주석만 바꾸면 빌드를 생략하고 경로·링크·참조와 diff를 확인한다.
  사용자의 다른 미커밋 변경은 이번 작업의 커밋에 섞지 않는다.

## Gradle 잠금 충돌

같은 worktree의 wrapper는 Gradle을 직렬화한다. exit code `75`와
`[YEOBAEK_GRADLE_LOCKED]`는 테스트·정적 분석 실패가 아니다.

1. 출력의 `ownerPid`를 확인하고 해당 프로세스가 끝날 때까지 기다린다.
2. 인자·옵션을 바꾸지 않은 동일 명령을 한 번 다시 실행한다.
3. 재실행도 충돌하면 새 owner 정보를 포함해 실행하지 못한 검증을 보고한다.

실행 중인 Gradle·데몬이나 `build/`를 강제 정리해 잠금을 우회하지 않는다.
marker 없이 코드 `75`만 반환되면 같은 충돌로 추정하지 않는다. 잠금 도구 자체의 실패는
재시도 대신 원인을 보고한다. wrapper를 재생성할 때 잠금 연결을 보존한다.
구현은 [`WorktreeGradleLock.java`](../../../gradle/WorktreeGradleLock.java)를 참조한다.

## 정적 분석 설정

설정·버전은 [`build.gradle`](../../../build.gradle),
[운영 PMD](../../../config/pmd/ruleset.xml), [테스트 PMD](../../../config/pmd/ruleset-test.xml),
[SpotBugs 제외 설정](../../../config/spotbugs/exclude.xml)을 원본으로 삼는다.
경고를 임의로 억제하지 않는다. 새 오탐 제외는 원인과 적용 범위를 확인받고 이유를 남긴다.

## 제외한 룰 기록

### PMD

| 룰 | 유지할 제외·조정의 이유 |
|---|---|
| `UnitTestShouldIncludeAssert` | MockMvc의 `andExpect` 검증을 assert로 인식하지 못한다. |
| `UnitTestContainsTooManyAsserts` | 한 결과의 여러 필드를 확인하는 테스트를 허용하도록 임계값을 조정한다. |
| `AbstractClassWithoutAbstractMethod` | Spring 테스트 공통 설정을 제공하는 추상 베이스 클래스가 있다. |
| `TestClassWithoutTestCases` | Testcontainers 설정 클래스를 테스트 클래스로 오인한다. |
| `AvoidDuplicateLiterals` | 운영·테스트 소스 모두 제외한다. 단순 중복만으로 상수화하지 않고, 같은 의미·역할의 값이 여러 곳에서 사용되는지를 기준으로 판단한다. PMD는 값의 의미·역할을 구분해 상수화의 적절성을 판단할 수 없으므로 이 규칙을 적용하지 않는다. |
| `MissingSerialVersionUID` | 예외 객체를 저장·전송하지 않으므로 직렬화 호환성을 관리하지 않는다. |

### SpotBugs

- `CT_CONSTRUCTOR_THROW`는 도메인 엔티티 패키지에 한정해 제외한다. JPA 프록시 조건과
  충돌하는 클래스 final화·생성자 private화나 제거 예정인 `finalize()` 도입으로 대응하지 않는다.
- `EI_EXPOSE_REP2`는 같은 JPA 엔티티의 식별성과 연관관계를 공유해야 하는 생성자·필드에
  한정한다. 방어적 복사가 관계를 깨뜨리기 때문이다. 정확한 대상은 제외 설정을 따르며
  패키지 전체나 다른 경고로 확대하지 않는다.
