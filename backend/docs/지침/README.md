# 작업별 지침

현재 변경에 해당하는 지침만 읽는다. 여러 책임을 변경하면 해당 문서를 함께 적용한다.

| 작업 | 지침 |
|---|---|
| 중요한 요구사항·설계가 미정인 작업 | [피드백 루프 하네스](프로세스/피드백_루프_하네스.md) |
| 도메인 상태·판단·값 객체 변경 | [도메인 모델링](설계/도메인_모델링.md) |
| 새 패키지·클래스 배치 | [패키지 구조](설계/패키지_구조.md) |
| JSON 컨트롤러 테스트 작성·검토 | [컨트롤러 테스트 하네스](코딩/컨트롤러_테스트_하네스.md) |
| Java 비공개 메서드 작성·수정 | [비공개 static 메서드](코딩/비공개_static_메서드.md) |
| 코드 변경 검증·커밋, Gradle 잠금 충돌 | [커밋 전 게이트](검증/커밋_전_게이트.md) |
| PR 작성·제출·갱신 | [백엔드 PR 작성 하네스](프로세스/백엔드_PR_작성_하네스.md) |

지침은 목적에 맞는 하위 디렉터리에 두고, 추가·이동·삭제할 때 이 표도 갱신한다.
같은 규칙은 한 문서에서 관리하고 필요한 곳에서 참조한다.
