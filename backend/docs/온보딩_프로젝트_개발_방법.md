# 프로젝트 개발 방법

## 작업 흐름

1. 요청과 관련 코드·명세를 확인한다. 구현을 바꾸는 중요한 미정은 개발자와 정한다.
2. 확정된 범위에서 구현하고 변경한 동작을 검증한다.
3. PR 제출을 맡은 경우 검증한 변경을 커밋·푸시하고 PR을 작성한다.
4. 팀원은 PR의 동작·설계·검증을 리뷰한다. 일반 작업은 develop에 통합하고,
   운영 반영은 main으로 PR을 제출한다.
