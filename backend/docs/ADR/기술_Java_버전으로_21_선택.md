# ADR: Java 버전으로 21 선택

## 상태

확정. 결정 근거 기록 2026-08-07 (개발자).

## 맥락

백엔드 언어가 Java로 확정된 상태에서
([기술_백엔드_언어로_Java_선택.md](기술_백엔드_언어로_Java_선택.md)),
사용할 Java 버전을 선택해야 한다. LTS 버전인 17과 21 중 하나를 선택한다.

## 검토한 선택지 (2026-08-07 개발자 기록)

### 선택지 A: Java 21

- 가상 스레드가 도입되어, I/O Bound 처리 속도가 향상되었다.
- JDK 17은 2026 ~ 2029년에 대부분 배포판에서 Premier Support가 종료된다.

### 선택지 B: Java 17

- Spring Boot 생태계를 사용할 때 최고 수준으로 안정적이다.
- 오래된 서드파티 라이브러리와 호환될 경우가 많다.

## 결정

**Java 21을 사용한다.**

## 근거 (2026-08-07 개발자 기록)

- I/O Bound가 많을 거라 예상되니, 가상 스레드 도입이 가능한 21이 유리하다.
- 21도 충분히 안정적이며, 17을 사용할 때 지원 종료가 머지 않았다는 리스크가 크다.

## 한계·트레이드오프

- 오래된 서드파티 라이브러리 중 21과 호환되지 않는 경우를 만날 수 있다.
