# 초대 웹 페이지 디자인

## 1. 목적
주 행동은 '여백 앱에서 열기'. 초대 사실, 초대코드, 앱 열기 순으로 읽는다.
앱 설치는 App Store / Google Play 링크로 제공한다.

## 2. 기준
Figma 파일 Heqck4ps4cbcXNhR7cP0xQ의 모바일 2072:38, PC 2072:72.
사용자가 확정한 Noto Sans KR, 화살표 없는 녹색 스토어 버튼, 최소 문구를 유지한다.
디자인 캡처를 화면 배경으로 사용하지 않는다. 로고·아이콘·배경 장식만 개별 에셋으로 사용한다.

## 3. 토큰
색상: paper #FAF7F2, ink #3C3833, secondary #6B645E, line #DED6CC,
surface #FFFFFF, forest #4C5B52.
Noto Sans KR 400/700을 로컬 파일로 제공한다.
크기/줄높이: 보조 11/18, 주 버튼 14/20, 스토어 20/27, 제목 22/30, 코드 26/34.
간격: 4, 12, 16, 24, 32px. 곡률: 버튼 8px, 로고 12px, 카드/스토어 20px.
스토어 그림자: 0 10px 26px rgba(60,56,51,.12).

## 4. 배치
Layout: 초대 페이지 - 좁은 폭에서도 읽을 수 있는 중앙 단일 열 -> center
(https://github.com/changeroa/StyleGallery/blob/main/patterns/centering/center.md);
scroll owner: document; anti-patterns: 고정 높이로 내용 자르기, 내부 중첩 스크롤, 가로 넘침.
콘텐츠 최대 폭 342px, 페이지 여백 24px, PC 여백 40px 64px.
브랜드와 본문 사이 32px, 본문 그룹 사이 24px.
앱 열기 버튼과 다운로드 영역 사이는 40px. 앱 열기 버튼이 숨겨진 상태에는 추가 간격을 넣지 않는다.
최소 화면 높이는 100svh, 내용이 길면 문서가 자연스럽게 스크롤한다.

## 5. 컴포넌트와 문구
브랜드: 44px 로고와 여백.
제목: 모임에 초대받았어요.
초대코드: 라벨, 코드 값, 44px 복사 버튼.
주 버튼: 여백 앱에서 열기, 높이 52px.
스토어: 버튼은 세로로 유지한다. 36px 아이콘과 이름을 12px 간격으로 묶어 버튼 가운데 정렬한다. 높이 64px, 버튼 사이 세로 간격 12px.
설치 안내: 설치 후 초대 링크를 다시 열어주세요.
PC 안내: 휴대폰에서 초대 링크를 열어주세요.
반복 설명, 소개 문구, 다운로드 화살표, 모임명·책 정보는 넣지 않는다.

## 6. 상태
유효한 코드: 카드·앱 링크를 제공한다. 모바일에서는 자동 실행을 한 번 시도한다.
코드 없음: 앱 다운로드 안내를 제공한다.
잘못된 코드: 링크를 다시 확인하도록 안내하고 앱 실행을 시도하지 않는다.
복사 실패: 코드 텍스트를 선택하고 수동 복사 방법을 안내한다.
실제 참여 여부는 앱과 기존 서버 API에서 결정한다.

## 7. 접근성
의미 있는 제목·링크·버튼, 키보드 포커스, 44px 이상 터치 영역.
코드 복사에 접근 가능한 이름을 제공한다. 상태 변경을 live region으로 알린다.
시안의 밝은 테마를 고정하며 모션 감소 설정을 존중한다.

## 8. 검증
390×844 모바일과 1280×960 PC를 Figma와 비교한다.
320px 폭, 200% 확대, 코드 없음/오류/중복, 앱 복귀 후 반복 실행 여부도 확인한다.
