# 책 소개 초안 지침

번역 리뷰와 수정을 마친 작품의 내용에 근거해 AI가 책 폴더의 `책_소개.txt`에 소개 초안을 작성한다.
소개는 독자가 어떤 책인지 이해하고 흥미와 읽을지 여부를 판단할 수 있게 돕는다.

## 작성 기준

- 소설은 인물·배경·출발 상황과 중심 갈등이나 질문을 구체적으로 소개한다. 비소설은 다루는 문제와 관점을 설명한다.
- 작품에서 확인되는 장면·관계·서술 방식 등 읽을 매력을 드러낸다. 추상적인 찬사나 근거 없는 수상·평가·효과를 덧붙이지 않는다.
- 결말·핵심 반전과 이를 쉽게 유추하게 하는 정보를 공개하지 않는다. 전체 줄거리 요약으로 대신하지 않는다.
- 간결한 2~3문장을 권장한다. 정확한 문장 수나 별도 제품 글자 수 제한을 기계적으로 강제하지 않는다.
- UTF-8 평문으로 저장한다. 제목·마크다운·HTML·목록·출처 주석·검토 메모 없이 소개 본문만 쓴다.

## 검토와 인계

원문·리뷰를 대조해 사실성, 구체적인 내용과 매력, 스포일러 여부, 자연스러운 한국어를 검토한다.
검토 결과는 완료 보고에 남기고 소개 본문에 섞지 않는다. 번역 본문·문단·문장 수에는 소개를 포함하지 않는다.

새 최종 변환은 비어 있지 않은 `책_소개.txt`를 검증하고 내용을 `ingest.json.description`에 반영한다.
앞뒤 공백은 제거하고 내부 개행은 보존하며, 메타데이터에 소개가 있어도 소개 파일을 기준으로 사용한다.
ZIP에는 소개가 반영된 JSON과 원래 소개 파일을 함께 보관한다. 소개의 존재를 운영자 검수 완료 증거로 간주하지 않는다.

AI 검토와 운영자 검수는 구별한다. 완료 보고에는 초안 경로와 **운영자 검수 후 등록** 단계를 적는다.
운영자는 ZIP의 소개를 검수한 뒤 JSON을 업로드한다. 수정이 필요하면 관리자 업로드의 소개 입력으로 교체하거나, `책_소개.txt`를 수정하고 최종 변환을 다시 실행한다. 기존 책도 관리자 화면에서 소개를 편집할 수 있다.
에이전트는 운영자의 승인이나 검수 완료를 자동 기록하지 않는다. 별도 승인 상태나 승인 플래그는 사용하지 않는다.

소개 없는 기존 ZIP은 서버에서 계속 사용할 수 있다. 기존 번역 작업을 새 변환기로 재생성할 때만
소개 파일을 보완하며, `--partial`과 구형 인제스트 정규화는 소개 없이 실행할 수 있다.
