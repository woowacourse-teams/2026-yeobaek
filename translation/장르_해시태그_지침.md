# 장르·해시태그 작성 지침

책을 웹소설처럼 친근하게 소개해 독자가 읽어볼 책을 고르고, 읽으며 떠오른 반응을 편하게 나누도록 돕는다.
번역 리뷰 후 작품을 근거로 작성하고, **완성된 태그 묶음이 독자에게 자연스럽게 읽히는지** 별도 검토한다.

## 산출물과 규격

- 장르는 자유롭게 작성해 `메타데이터.json.genres` 문자열 배열에 **장르명당 최대 255자**로 넣는다. 새 산출물에는 1개 이상 필요하며, 작품을 설명하는 데 필요한 장르만 고른다. 예: 로맨스, 비극. 공통 목록이나 임의의 개수 상한은 두지 않는다.
- 해시태그는 같은 파일의 `hashtags` 문자열 배열에 **1~5개, 문구당 최대 10자**로 넣는다. 장르와 해시태그의 글자 수는 Unicode 코드 포인트 기준이다.
- `#` 없이 문구만 쓴다. 자동 공백 제거·중복 제거에 기대지 않고, 작성자가 최종 문구를 정한다. 서비스의 반환 순서는 보장하지 않는다.
- 새 최종 변환에는 두 필드가 모두 필요하다. 공식 변환기는 메타데이터의 값을 그대로 `ingest.json`에 반영하며 메타데이터와 JSON을 ZIP에 보관한다. 업로드에는 기존처럼 JSON 하나와 표지 한 개만 사용한다.

```json
{
  "genres": ["로맨스", "풍자"],
  "hashtags": ["첫인상", "신분차이"]
}
```

## 표현 기준

- 작품을 모르는 독자도 태그를 읽고 인물의 역할, 인물 관계, 이야기의 배경·전개나 분위기 중 무엇을 짐작할 수 있는지 확인한다. 여러 태그를 쓸 때는 각 태그가 서로 다른 정보를 더하도록 고른다. 작품에 필요한 만큼만 쓴다.
- 후보가 비슷하게 적절하면 초반부터 독자가 인물의 편을 들거나, 관계를 예상하거나, 사건에 한마디 얹게 되는 지점을 잘 보여주는 태그를 우선한다.
- 등장인물의 이름은 해시태그에 넣지 않는다. 이름으로 설명하던 역할이나 관계가 중요하면 `홈즈와왓슨`보다 `천재탐정`이나 `단서추리`처럼 독자가 내용을 예상할 수 있는 말을 고른다. `빅브라더`처럼 인물 소개를 넘어 작품의 핵심 설정을 가리키는 상징은 연상 키워드로 쓸 수 있다.
- `비극` 같은 장르는 `genres`에서 관리한다. `시와산문`, `자전적기록`처럼 글의 형식이나 서술 방식만 설명하는 말도 해시태그에서 뺀다.
- 직업이나 장소는 `해군장교`, `신학교`처럼 인물의 역할이나 사건이 벌어지는 환경을 상상하는 데 도움이 될 때 쓴다. 사물이나 상징은 이야기에서 맡는 역할이 태그나 태그 묶음에서 드러나는지 확인한다. 맥락을 짐작하기 어렵다면 사건이나 관계가 보이도록 구체화하거나 뺀다. 추리 단편집의 `사라진경주마`처럼 한 사건에만 해당하는 소재는 그 사건이 책 전체를 대표하는지 확인한다.
- 뜻이 여럿인 말은 의도한 의미가 바로 읽히게 구체화한다. 공연을 하는 집단을 가리키는 `극단`은 `연극단`처럼 쓸 수 있다. `오해`, `공동체`처럼 범위가 넓거나 `작가와인물`처럼 관계가 분명하지 않은 말도 작품 맥락에 맞춰 고친다. 더 익숙한 표현으로 뜻을 전달하기 어려우면 뺀다.
- `체면`, `익살`처럼 인물 한 명의 성향이나 행동만 설명하는 말은 뺀다. 그 행동이 관계나 갈등을 만든다면 둘 사이에 벌어지는 일을 표현한다. 분위기 태그는 형용사와 명사 모두 쓸 수 있다. `유쾌한`이나 `블랙코미디`처럼 장면과 말투에서 느껴지는 분위기가 자연스럽게 전해지는 표현을 고른다. 표현이 추상적이거나 문학적으로 느껴지면 독자가 쉽게 알아볼 말로 바꾼다.
- 짧고 익숙한 취향 키워드를 기본으로 쓴다. `혐관맛집`, `관계성맛집`, `두뇌싸움`처럼 독자에게 익숙한 표현도 실제 관계나 전개에 잘 맞을 때 쓴다. 문장형 밈이나 작품에 억지로 끼워 맞춘 유행어는 뺀다.
- `반전`으로 전개의 특징을 알릴 수 있다. 반전에서 무엇이 뒤집히는지, 구체적인 결말과 인물의 최종 운명은 태그에서 뺀다.
- 고전의 갈등을 현대적인 말로 표현하되 작품에 없는 회귀·빙의·능력·관계·전개를 만들어내지 않는다. 성격이나 관계를 단정하는 표현은 실제 장면으로 뒷받침한다.
- 읽는 데 낯선 은어가 겹치거나, 붙여 쓴 문장이 이해되지 않거나, 해설문을 짧게 잘라 붙인 느낌이면 다시 쓴다. 긴 설명이 필요한 태그는 더 분명한 표현으로 바꾼다.

### 참고한 실제 서비스

- [리디 키워드 검색](https://ridibooks.com/keyword-finder/romance)은 소재·관계·인물·분위기를 구분한다. 실제 키워드의 예는 ‘첫사랑’, ‘라이벌/앙숙’, ‘성장물’이다.
- [노벨피아 작품 상세](https://novelpia.com/novel/233097)에서는 ‘일상’, ‘대학교’, ‘사업’처럼 짧은 특징을 함께 표시한다. [작품 목록](https://novelpia.com/plus/subscription)에서도 소재와 전개를 조합한 태그를 확인할 수 있다.

이 목록은 짧은 표현을 고를 때 참고한다. 우리 서비스용 태그는 작품별로 정한다.

### 우리 서비스용 작성 예시

아래는 플랫폼에서 가져온 태그가 아니라 작품 내용을 바탕으로 작성한 예다. 개별 번역본에 적용할 때도 실제 내용과 대조한다.

- **『오만과 편견』** `첫인상`, `신분차이`. 두 사람이 처음에 서로를 어떻게 판단하는지와 관계에 영향을 주는 사회적 차이를 담는다.
- **『순수의 시대』** `뉴욕사교계`, `금지된사랑`, `삼각관계`. 이야기의 배경과 사랑에 따르는 제약, 인물 관계를 각각 보여준다.
- **『설득』** `해군장교`, `미련`, `재회`. 한 인물의 직업과 다시 만난 두 사람 사이에 남아 있는 감정을 보여준다.
- **『수레바퀴 아래서』** `입시압박`, `신학교`. 주인공이 받는 압박과 그가 생활하는 환경을 함께 보여준다.
- **『변신』** `바퀴벌레`, `가족갈등`, `소외`. 익숙한 연상어를 가족 관계와 함께 제시한 조합이다. 벌레가 사건에서 어떤 역할을 하는지 독자가 짐작하기 어렵다면 `벌레변신`처럼 설정이 드러나는 표현을 후보로 검토한다.
- **『데미안』의 검토 예시.** `알`은 작품을 읽은 뒤에 의미를 알아보기 쉬운 상징이다. 태그만 보고 책을 고르는 독자에게 주제를 전하려면 `선과악`을 후보로 검토할 수 있다.
- **『셜록 홈즈의 회상록』** `천재탐정`, `단서추리`, `두뇌싸움`. 여러 사건에서 단서를 엮는 추리 방식과 홈즈가 자신을 위협하는 강적과 맞서는 긴장을 담는다.
- **『침입자들』** `생존`, `고립`, `혐관맛집`. 원수 사이인 두 사람이 고립되어 서로를 마주하는 상황을 담는다.
- **『작은 아씨들』** `네자매`, `따뜻한`, `관계성맛집`. 서로 성격이 다른 네 자매가 부딪히고 챙겨 주는 관계를 보여준다.
- **『노인과 바다』** `고독`, `생존`, `바다낚시`. 어종을 나열하기보다 어부가 홀로 바다에서 겪는 일을 보여준다.
- **『이야기꾼』** `기차`, `입담`, `블랙코미디`. 기차에서 두 사람이 아이들에게 서로 다른 이야기를 들려주는 상황과 짓궂은 웃음을 담는다.
- **『방어용 다이아몬드』** `눈치싸움`, `유쾌한`. 말을 이어 가려는 상대에게 더 황당한 이야기로 받아치는 상황과 작품의 분위기를 보여준다.
- **어색한 예:** `인간존재론적성찰`처럼 해설 제목만 옮기면 책의 구체적인 매력이 잘 드러나지 않는다. `명작`, `필독서`만 나열하면 어떤 경험을 할지 알기 어렵다.
- **내용과 다른 예:** 『변신』에 `먼치킨성장물`을 붙이면 실제 전개와 다른 기대를 준다. 어울리지 않는 인기 키워드를 가져오지 않는다.

## 독립 검토와 업로드

작성자와 다른 검토자가 원문·번역·리뷰를 대조해 다음을 확인하고, 선정 근거와 수정 내역을 리뷰 보고서에 남긴다.

1. 장르 목록이 이 책을 소개하는 데 적절하고, 근거 없는 분류가 섞이지 않았는가?
2. 태그마다 작품 근거가 있는가? 인물 이름처럼 보이는 표현은 `빅브라더`처럼 핵심 설정을 가리키는 상징일 때 허용한다. 장르·형식 분류가 섞이지 않았는가? 직업·장소·사물·상징이 인물이나 상황을 그리는 데 도움이 되는가? 소재가 한 사건에만 등장한다면 책 전체를 대표할 만큼 비중이 있는가?
3. 작품을 모르는 독자도 각 태그가 가리키는 관계·갈등·상황이나 분위기를 짐작할 수 있는가? 짧고 익숙한 표현이고 의도한 뜻으로 읽히는가? 인물 한 명의 성향이나 행동만 설명하는 말, 문장형 밈, 작품에 맞지 않는 유행어가 섞이지 않았는가? 태그가 서로 다른 정보를 더하는가?
4. `반전` 태그가 전개의 특징만 알리는가? 반전의 구체적인 내용이나 결말을 공개하거나 작품에 없는 설정을 약속하지 않는가?
5. `#` 없는 1~5개 문구이며 각 10자 이내인가? 완성된 문구를 최종 검토했는가?

수정은 `메타데이터.json`에서 하고 공식 변환을 다시 실행한다. 업로드 담당자는 검토된 메타데이터와 `ingest.json.genres/hashtags`, ZIP 내부 값을 정확히 대조한다. 변환기의 형식 검증 통과를 자연스러움·사실성 검토 완료로 간주하지 않는다.

과거 인제스트와 부분 검증·구형 정규화에서는 두 필드를 선택 값으로 유지한다. 기존 도서의 장르·해시태그 보강은 별도 요청이 있을 때 검토가 끝난 목록을 기준으로 지정된 관리자에서 반영한다. 관리자 API는 `#`를 검사하거나 자동 보정하지 않는다.
