# Translation Workspace Rules

이 디렉터리는 영문 고전 번역과 서버 인제스트 JSON 생성을 위한 작업 공간이다. 이 디렉터리 또는 하위 책 폴더에서 번역·검증·인제스트 작업을 맡으면 아래 규칙을 자동 적용한다.

## 필수 하네스

- 사용자가 "지침에 따라 번역해줘"처럼 축약해서 요청해도 `번역_하네스.md`의 전체 파이프라인을 수행한다.
- 작업 시작 전에 `번역_하네스.md`, `번역_지침.md`, `번역_리뷰_지침.md`를 읽고 따른다.
- `인제스트_변환.py`만 JSON을 생성한다. AI가 `ingest.json`을 직접 작성하거나 수정하지 않는다.
- `메타데이터.json`의 모든 `authors[]`에는 서비스 식별용 `name`과 검증된 `isni`가 있어야 한다. 사용자가 메타데이터를 주지 않으면 신뢰할 수 있는 출처에서 후보를 추론한 뒤 사용자 확인을 받은 후에만 확정한다. ISNI를 추측하거나 임의 생성하지 않는다.
- `--force`, `--no-verify`로 검증을 우회하지 않는다.
- `python3`, `python`, `py`가 없으면 Codex App의 workspace dependency Python을 찾아 `인제스트_변환.py` 실행에 사용한다. 시스템 Python 부재를 작업 중단 사유로 삼지 않는다.

## 기본 완료 조건

- `장_정보.md`를 만든 뒤 장별 라인 범위와 문단 수를 기준으로 번역한다.
- `번역_공통_가이드.md`를 먼저 만들고, 인명·호칭·존대/반말·고유명사·톤앤매너를 모든 병렬 작업자가 공유한다.
- 남은 장이나 청크가 2개 이상이면 가능한 범위에서 병렬 번역한다. 긴 장은 문단 범위별 청크로 나누고, 코디네이터가 장 단위 파일로 병합한다.
- 전체 번역 후 `번역_리뷰_지침.md` 기준 리뷰를 반드시 수행하고 `리뷰/`에 보고서를 남긴다.
- 리뷰 수정 후 문단 수 검증을 다시 통과시킨다.
- 최종 변환은 `인제스트_변환.py`로 실행하고, `ingest.json`과 `책이름.zip`을 생성한다. ZIP 파일명은 `메타데이터.json`의 `title`을 기준으로 하며 공백은 `_`로 바꾼다.

## 산출물 안내

- 사용자에게 최종 보관 파일은 책 폴더의 `책이름.zip`이라고 안내한다. 예: `오만과_편견.zip`.
- 완료 보고에는 병렬 분담 요약, 검증 결과, 리뷰 수행 여부, ISNI 확인 결과, `ingest.json` 경로, `책이름.zip` 경로를 포함한다.
