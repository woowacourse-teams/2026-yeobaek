# 번역 작업 지침

이 디렉터리는 고전 문학의 한국어 번역·리뷰·표지·인제스트 작업 공간이다.
세부 절차는 아래 문서를 원본으로 삼고 현재 단계에 해당할 때 읽는다.

| 작업 | 지침 |
|---|---|
| 전체 번역·인제스트 요청 | [번역 하네스](번역_하네스.md)의 준비부터 최종 ZIP까지 수행 |
| 번역 작성·수정 | [번역 지침](번역_지침.md), 해당 책의 번역 공통 가이드 |
| 번역 리뷰 | [리뷰 지침](번역_리뷰_지침.md) |
| 책 소개 초안 작성·검토 | [책 소개 지침](책_소개_지침.md) |
| 표지 생성·검수 | [표지 하네스](표지_하네스.md) |

## 유지할 경계

- 원문에서 한국어로 직접 번역하고 문단 구조를 보존한다. 원문 언어와 공통 표기는
  해당 책의 장 정보·공통 가이드로 공유한다.
- 인제스트 JSON과 최종 ZIP은 [인제스트 변환기](인제스트_변환.py)로 생성한다.
  JSON을 수작업으로 고치거나 `--force`·`--no-verify`로 검증을 우회하지 않는다.
- 저자 식별·ISNI가 해결되지 않으면 최종 변환을 중단한다. 메타데이터 조사는 번역 하네스를 따른다.
- 전체 번역 요청은 리뷰, 표지 A~G의 구조·시각 검수, 문장 재결합 검증과 원문 바이트를
  보존한 ZIP까지 마쳐야 완료다. 상세 완료 보고 항목은 번역 하네스의 완료 보고 절을 따른다.
- 번역 리뷰 후 `책_소개.txt`에 소개 초안을 작성한다. 최종 변환기는 이를
  `ingest.json.description`에 반영하고 JSON과 소개 파일을 ZIP에 함께 보관한다. 서비스 등록 전 운영자가 검수한다.
- 표지는 내장 이미지 생성 도구를 기본으로 사용한다. API·CLI나 다른 모델 사용은 사용자 확인이 필요하다.
- 시스템 Python이 없으면 Codex의 workspace dependency Python으로 변환기를 실행한다.
