# Translation Workspace Rules

이 디렉터리는 원문 언어와 국가에 관계없이 저작권이 만료된 고전 문학을 한국어로 번역하고, 책 표지 시안과 문장 단위 서버 인제스트 JSON을 생성하기 위한 작업 공간이다. 이 디렉터리 또는 하위 책 폴더에서 번역·표지·검증·인제스트 작업을 맡으면 아래 규칙을 자동 적용한다.

## 필수 하네스

- 사용자가 "지침에 따라 번역해줘"처럼 축약해서 요청해도 `번역_하네스.md`의 전체 파이프라인을 수행한다.
- 작업 시작 전에 `번역_하네스.md`, `번역_지침.md`, `번역_리뷰_지침.md`, `표지_하네스.md`를 읽고 따른다.
- `인제스트_변환.py`만 JSON을 생성한다. AI가 `ingest.json`을 직접 작성하거나 수정하지 않는다. 변환기는 각 번역 문단을 `passages[].sentences[].content`로 분리하고, 문장 배열을 다시 이었을 때 원래 문단이 완전히 복원되는지 검증한다.
- `메타데이터.json`의 모든 `authors[]`에는 서비스 식별용 `name`과 검증된 `isni`가 있어야 한다. 사용자가 메타데이터를 주지 않으면 국립중앙도서관 ISNI-KOREA(<https://www.nl.go.kr/isni/>)를 우선 검색하고, 인물 상세 화면의 생몰년·다른 이름·활동 정보를 대조한 뒤 상세 URL을 출처로 기록한다. 레코드가 없거나 모호할 때만 다른 국가도서관·국제 권위 출처로 보완한다. 후보는 사용자 확인 후에만 확정하며 ISNI를 추측하거나 임의 생성하지 않는다.
- `--force`, `--no-verify`로 검증을 우회하지 않는다.
- `python3`, `python`, `py`가 없으면 Codex App의 workspace dependency Python을 찾아 `인제스트_변환.py` 실행에 사용한다. 시스템 Python 부재를 작업 중단 사유로 삼지 않는다.
- 표지 시안은 `표지_하네스.md`에 따라 기본 내장 이미지 생성 도구로 A~G를 각각 독립 생성한다. 내장 도구 실패 시 사용자 확인 없이 API·CLI 또는 다른 모델로 전환하지 않는다.

## 기본 완료 조건

- 원문 언어를 BCP 47 태그와 언어명으로 식별해 `장_정보.md`와 `번역_공통_가이드.md`에 기록한다. 출처가 선언한 언어와 실제 텍스트의 식별 결과가 다를 때만 확인하며, 특정 언어의 허용 목록이나 비영어 원문 차단 규칙을 두지 않는다.
- 모든 언어는 원문에서 한국어로 직접 번역한다. 사용자가 별도로 요청하지 않는 한 영어 중간 번역본을 만들거나 영어를 거쳐 번역하지 않는다.
- `장_정보.md`를 만든 뒤 장별 라인 범위, 문단 수, 문자 수, 추정 토큰 수, 권장 청크를 기준으로 번역한다.
- `번역_공통_가이드.md`를 먼저 만들고, 모든 언어에 적용하는 공통 코어와 원문 언어별 프로필을 분리한다. 언어별 프로필에는 문법, 호칭, 시제·상, 문장부호, 고유명사, 방언·시대어 처리 원칙을 기록하고 모든 병렬 작업자가 공유한다.
- 남은 장이나 청크가 2개 이상이면 가능한 범위에서 병렬 번역한다. 기본 청크 한도는 150문단, 24,000자, 추정 8,000토큰이며 먼저 한도에 닿는 문단 경계에서 나눈다. 한 문단만으로 한도를 넘으면 그 문단을 독립 청크로 둔다. 한 작업자에게 여러 장이나 청크를 묶어 배정할 때도 합산 작업량이 같은 한도를 넘지 않게 한다. 필요하면 `--list-chapters`의 청크 한도 CLI 옵션으로 책에 맞게 조정하고, 코디네이터가 청크를 장 단위 파일로 병합한다.
- 전체 번역 후 `번역_리뷰_지침.md` 기준 리뷰를 반드시 수행하고 `리뷰/`에 보고서를 남긴다.
- 리뷰 수정 후 문단 수와 문장 분리·재결합 검증을 다시 통과시킨다.
- 리뷰와 메타데이터 표기 확정 후 `표지_브리프.json`을 작성하고 `표지_시안_준비.py prepare`로 A~G 프롬프트를 생성한다. 준비 스크립트는 모든 프롬프트에 언어와 소재명에 의존하지 않는 조건부 안전 규칙을 넣어, 편지·문서·책·신문·간판 같은 문자 표면 소재를 사용할 때 제목·작가명 외의 모든 표면을 무문자로 유지하게 한다.
- `표지/A.png`부터 `G.png`까지 정확히 7개를 만들고 구조 검증과 시각 검수를 모두 통과시킨다. 이미지 생성·검수가 끝나기 전에는 전체 완료를 선언하지 않는다.
- 최종 변환은 `인제스트_변환.py`로 실행하고, 문단별 `sentences`가 최소 1개이며 각 `content`가 공백이 아니고 UTF-8 65,535바이트 이하인지 확인한 뒤 `ingest.json`과 `책이름.zip`을 생성한다. ZIP 파일명은 `메타데이터.json`의 `title`을 기준으로 하며 공백은 `_`로 바꾼다.

## 산출물 안내

- 사용자에게 최종 보관 파일은 책 폴더의 `책이름.zip`이라고 안내한다. 예: `오만과_편견.zip`.
- 완료 보고에는 원문 언어와 직접 번역 여부, 병렬 분담·작업량 요약, 장·문단·문장 수와 문장 재결합 검증 결과, 리뷰 수행 여부, ISNI 확인 결과, 표지 A~G 경로와 표지 검증 결과, 사용한 이미지 생성 경로, `ingest.json` 경로, `책이름.zip` 경로를 포함한다.
